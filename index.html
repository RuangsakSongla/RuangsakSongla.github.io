[Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป แนะนำ) - [Git](https://git-scm.com/) - ตัวจัดการแพ็กเกจ: `npm`, `pnpm` หรือ `yarn` ### ขั้นตอนการรัน (Installation) 1. **Clone repository:** ```bash git clone https://github.com//.git cd ``` 2. **ติดตั้ง Dependencies:** ```bash npm install # หรือ pnpm install ``` 3. **ตั้งค่า Environment Variables (ถ้ามี):** ```bash cp .env.example .env.local ``` 4. **เริ่มรันโปรเจกต์ในโหมด Development:** ```bash npm run dev ``` 5. เปิดเบราว์เซอร์ไปที่: `http://localhost:3000` (หรือพอร์ตที่ระบบระบุ) --- ## 📂 โครงสร้างโฟลเดอร์ (Project Structure) ```text ├── public/ # ไฟล์ Static ทั่วไป เช่น รูปภาพ, ไอคอน ├── src/ │ ├── assets/ # สื่อและสไตล์ชีต │ ├── components/ # Reusable UI Components │ ├── pages/views/ # หน้าต่าง ๆ ของระบบ │ ├── services/ # จัดการ API Call หรือ Business Logic │ └── utils/ # ฟังก์ชันช่วยเหลือ (Helper Functions) ├── .env.example # ตัวอย่าง Environment variables ├── package.json # ข้อมูลโปรเจกต์และ Dependencies └── README.md # เอกสารแนะนำโปรเจกต์ ``` --- ## 📝 บันทึกการทดสอบ (Dev Notes & Changelog) -
